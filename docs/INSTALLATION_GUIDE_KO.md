# SubSync 설치 가이드

SubSync는 YouTube에서 영어·한국어 이중자막, 스크립트, 단어 학습 및 AI Video Tutor를 제공하는 Chrome 확장 프로그램입니다.

## 1. 설치 전 준비

### 지원 환경

- Google Chrome
- Manifest V3 확장 프로그램을 지원하는 Chrome 환경
- `https://www.youtube.com/watch` 형태의 YouTube 영상 페이지
- 배포 환경에 맞게 설정된 SubSync 백엔드
- Google 로그인 기능을 사용하는 경우, 운영자가 설정한 Supabase Auth 및 Google OAuth

> 지원 범위는 배포된 확장 프로그램의 버전과 운영 환경에 따라 달라질 수 있습니다. 확장 프로그램은 현재 `https://www.youtube.com/*` 페이지에 콘텐츠 스크립트를 주입하도록 구성되어 있습니다.

### 배포 전 운영자 확인

공개 배포본은 사용자가 별도의 서버 주소나 API 키를 입력하지 않아도 동작해야 합니다. 다음 항목은 사용자에게 안내하기 전에 운영자가 먼저 확인해야 합니다.

- 프론트엔드 API 주소가 로컬 주소가 아닌 HTTPS 운영 주소인지 확인합니다.
- Tutor API, 사전 API, 단어 저장·조회 API가 운영 백엔드에 등록되어 있는지 확인합니다.
- Supabase Auth와 Google OAuth redirect URL이 배포된 확장 프로그램 ID와 일치하는지 확인합니다.
- 브라우저 확장 프로그램에 `service_role` 키, JWT secret, Google client secret을 포함하지 않습니다.
- 개인정보처리방침 URL과 고객지원 URL을 Chrome Web Store 등록 정보에 입력합니다.

현재 저장소 상태의 배포 전 확인 항목은 [배포 전 체크리스트](RELEASE_CHECKLIST_KO.md)에 정리되어 있습니다.

## 2. Chrome Web Store에서 설치

Chrome Web Store 등록이 완료된 이후 일반 사용자는 다음 순서로 설치합니다.

1. Chrome에서 `[SubSync Chrome Web Store URL]`을 엽니다.
2. 확장 프로그램 이름과 게시자가 공식 SubSync 배포본인지 확인합니다.
3. **Chrome에 추가**를 선택합니다.
4. 권한 안내를 확인한 뒤 설치를 승인합니다.
5. Chrome 오른쪽 상단의 퍼즐 모양 **확장 프로그램** 아이콘을 선택합니다.
6. SubSync 오른쪽의 고정 아이콘을 선택하면 주소 표시줄 옆에 빠르게 표시할 수 있습니다.
7. 새 YouTube 영상 페이지를 열거나 이미 열려 있던 YouTube 탭을 새로고침합니다.

설치 후 YouTube 영상 화면에 SubSync 퀵바가 표시되면 설치가 완료된 것입니다.

## 3. 개발자 모드로 설치

Chrome Web Store에 등록하기 전 내부 테스트나 사내 배포가 필요한 경우 압축 해제된 확장 프로그램을 설치할 수 있습니다.

### 3.1 배포 파일 준비

1. 배포 ZIP 파일을 내려받습니다.
2. ZIP 파일을 일반 폴더에 압축 해제합니다.
3. 압축 해제한 폴더의 최상위에 `manifest.json`이 있는지 확인합니다.
4. `manifest.json`이 하위 폴더 안에 있다면 그 하위 폴더를 선택해야 합니다.

예시 구조:

```text
SubSync-release/
├─ manifest.json
├─ popup.html
├─ privacy.html
├─ src/
├─ styles/
└─ assets/
```

### 3.2 Chrome에 불러오기

1. Chrome 주소 표시줄에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**를 선택합니다.
4. `manifest.json`이 들어 있는 배포 폴더를 선택합니다.
5. SubSync 카드가 목록에 나타나는지 확인합니다.
6. YouTube 탭이 이미 열려 있었다면 해당 탭을 새로고침합니다.
7. 주소 표시줄 옆 퍼즐 아이콘에서 SubSync를 고정합니다.

> 개발자 모드 설치는 내부 테스트용입니다. 일반 사용자에게는 Chrome Web Store 설치 방법을 안내하는 것을 권장합니다.

## 4. Chrome 권한 안내

설치 시 Chrome이 표시하는 권한은 SubSync 기능을 제공하기 위해 사용됩니다.

| 권한 | 사용 목적 |
| --- | --- |
| `storage` | 테마·폰트·자막·튜터 관련 설정과 브라우저 학습 기록을 저장합니다. |
| `activeTab` | 현재 YouTube 탭의 영상과 자막 화면에 학습 UI를 표시합니다. |
| `webRequest` | YouTube가 자막을 요청하는 시점을 관찰하여 현재 영상에 맞는 자막을 불러오는 데 사용합니다. |
| `identity` | Google OAuth 로그인 창을 열고 로그인 세션을 관리하는 데 사용합니다. |
| YouTube 호스트 접근 | YouTube 영상 페이지, 자막, 영상 제목·썸네일을 기능에 필요한 범위에서 처리합니다. |
| 백엔드·Supabase 호스트 접근 | Tutor, 인증 및 배포된 SubSync 서버와 통신하는 데 사용합니다. |

SubSync는 외부 서버에서 JavaScript나 WebAssembly 코드를 내려받아 실행하지 않으며, 확장 프로그램에 포함된 코드를 실행합니다. 자세한 정보는 [개인정보처리방침](../privacy.html)을 확인합니다.

## 5. 최초 실행

1. 자막이 제공되는 YouTube 영상을 엽니다.
2. 영상 페이지가 완전히 로드될 때까지 잠시 기다립니다.
3. 화면 위에 `SubSync · ON` 퀵바가 나타나는지 확인합니다.
4. 패널이 보이지 않으면 페이지를 새로고침합니다.
5. 퀵바의 `SubSync · ON` 버튼을 선택하면 SubSync 기능을 켜거나 끌 수 있습니다.
6. 처음 로그인할 때는 패널의 **로그인** 버튼을 선택한 뒤 Google 계정으로 진행합니다.

로그인이 완료되면 버튼이 **로그아웃**으로 변경됩니다. 로그인 및 저장 기능은 운영 환경의 Supabase Auth 설정에 따라 사용할 수 있습니다.

## 6. 업데이트

### Chrome Web Store 설치본

Chrome이 자동으로 업데이트합니다. 즉시 업데이트하려면 다음과 같이 진행합니다.

1. `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **업데이트**를 선택합니다.
4. 열려 있는 YouTube 탭을 새로고침합니다.

### 개발자 모드 설치본

1. 새 배포 폴더를 준비합니다.
2. `chrome://extensions`에서 기존 SubSync 카드의 **새로고침** 아이콘을 선택하거나 기존 항목을 삭제한 뒤 다시 불러옵니다.
3. YouTube 탭을 새로고침합니다.
4. 버전이 변경되었는지 확장 프로그램 카드에서 확인합니다.

## 7. 삭제

1. `chrome://extensions`를 엽니다.
2. SubSync 카드의 **삭제**를 선택합니다.
3. 삭제를 확인합니다.

확장 프로그램 삭제 시 Chrome 확장 프로그램 저장소에 남아 있던 로컬 설정과 로컬 학습 기록이 함께 삭제될 수 있습니다. 서버에 저장된 데이터의 삭제는 운영자가 제공하는 데이터 삭제 절차를 따릅니다.

## 8. 문제 해결

### 퀵바나 패널이 보이지 않습니다.

- 주소가 `https://www.youtube.com/watch...`인지 확인합니다.
- `chrome://extensions`에서 SubSync가 사용 설정되어 있는지 확인합니다.
- YouTube 탭을 새로고침합니다.
- 개발자 모드 설치본이라면 확장 프로그램 카드에서 오류가 표시되는지 확인합니다.
- 다른 확장 프로그램이 페이지 UI를 가리는지 확인합니다.

### 자막이 표시되지 않습니다.

- 현재 영상에 영어 자막 또는 사용할 수 있는 자막 트랙이 있는지 확인합니다.
- YouTube 기본 자막을 켠 뒤 SubSync 새로고침 버튼이나 페이지 새로고침을 사용합니다.
- 잠시 뒤 다시 시도합니다. YouTube 자막 요청이 제한되면 HTTP 429 안내가 표시될 수 있습니다.
- 자막 인증값이나 토큰을 사용자 입력으로 요구하지 않습니다. 반복 실패 시 운영자에게 영상 URL과 오류 문구를 전달합니다.

### AI Tutor가 답변하지 않습니다.

- 운영 백엔드가 실행 중인지 확인합니다.
- 네트워크와 로그인 세션을 확인합니다.
- 질문을 짧게 다시 입력합니다.
- AI provider의 일시적인 제한이나 장애가 발생했을 수 있습니다.

### 저장소가 비어 있거나 로그인 화면이 표시됩니다.

- 저장소의 단어와 시청기록은 로그인 상태에서 확인할 수 있습니다.
- 로그인 후 저장소 탭을 다시 엽니다.
- 배포 환경에서 단어 API가 구성되지 않은 경우 브라우저 임시 저장으로 표시될 수 있습니다.
- 브라우저 데이터 또는 확장 프로그램을 삭제하면 로컬 기록이 사라질 수 있습니다.

## 9. 보안 주의사항

- 사용자에게 API 키, Supabase 키, 비밀번호, refresh token을 입력하도록 안내하지 않습니다.
- 운영자가 비밀값을 확장 프로그램 번들, README, 문서, 스크린샷에 포함하지 않습니다.
- AI Tutor 질문을 입력할 때 이메일, 비밀번호, 주민등록번호 등 민감정보를 입력하지 않는 것을 권장합니다.
